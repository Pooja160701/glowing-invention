# Rules of Engagement

1. Test only the local deliberately vulnerable target.
2. Verify the target before active scanning.
3. Prefer non-destructive validation.
4. Do not test unrelated hosts discovered during reconnaissance.
5. Use only laboratory accounts and data.
6. Stop if testing causes instability.
7. Sanitize tokens, passwords, cookies, and personal data before committing evidence.
8. Record enough information for another tester to reproduce the finding.
9. Remove the lab container when testing is complete.

## Evidence Policy
Screenshots and HTTP captures must contain no live secrets. Replace sensitive values with [REDACTED].
