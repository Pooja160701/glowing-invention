# Excel Reporting Model

## Workbook Tabs

1. `Executive_KPIs`
2. `Acquisition`
3. `Activation`
4. `Retention`
5. `Quality`
6. `Feedback`

## Recommended Excel Features
- Structured tables
- PivotTables
- PivotCharts
- XLOOKUP
- SUMIFS / COUNTIFS
- Conditional formatting
- Data validation
- Scenario assumptions

## Example Calculations

**Activation Rate**
`=Activated_Users/Onboarded_Users`

**Import Completion Rate**
`=Import_Completed/Import_Starts`

**Correction Rate**
`=Corrected_Transactions/Categorized_Transactions`

**Notification Opt-out Rate**
`=Notification_Optouts/Notification_Recipients`

The workbook should separate raw/synthetic data from calculated reporting tables so assumptions remain auditable.
