# FinFlow — BI & Reporting

> **Status:** BI specification with synthetic sample data. No external BI workspace was connected or modified.

## BI Tools

| Tool | Intended Use |
|---|---|
| Excel | Lightweight analysis, planning, what-if analysis |
| Power BI | Executive KPI dashboard and operational reporting |
| Tableau | Interactive product and behavioral exploration |
| Looker | Governed semantic metrics and reusable explores |
| Metabase | Self-service product and operations reporting |

## Canonical Reporting Layers

1. Executive KPI overview
2. Acquisition and activation
3. Engagement and retention
4. Product quality
5. Customer feedback
6. Trust, privacy, and operational guardrails

All dashboard examples use synthetic data unless explicitly connected to production sources.
