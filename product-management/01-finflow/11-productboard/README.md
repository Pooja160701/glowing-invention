# FinFlow — Productboard Product Management Setup

> **Status:** Specification / import-ready artifact. No external Productboard workspace was connected or modified.

## Proposed Productboard Structure

**Customer Needs → Insights → Features → Initiatives → Outcomes**

## Productboard Areas

- Customer Needs
- User Insights
- Feature Ideas
- Product Initiatives
- Prioritization
- Roadmap
- Outcome Tracking

## Productboard Principle

Productboard should connect customer evidence to product decisions.

The portfolio flow is:

**Research Evidence → Customer Need → Feature → Initiative → Outcome Metric**

A feature should not be prioritized solely because it is technically interesting or requested in isolation.
