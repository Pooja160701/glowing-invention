# FinFlow — User Story Map

## Backbone

| Journey Stage | User Activities | Representative Stories |
|---|---|---|
| Start | Create profile, understand privacy | US-001, US-002 |
| Import | Upload and validate transactions | US-003, US-004 |
| Understand | Review categories and dashboard | US-005, US-006, US-007, US-008 |
| Plan | Create budgets and goals | US-009, US-012 |
| Monitor | Track budgets and goals | US-010, US-011, US-013 |
| Act | Review and act on insights | US-014, US-015, US-016 |
| Stay informed | Configure and receive alerts | US-017, US-018 |
| Improve | Product analytics and feedback | US-019, US-020 |
| Control | Review and manage data | US-021, US-022 |

## MVP Slice

The first usable vertical slice should support:

**Create profile → understand data use → import transactions → review categories → view dashboard → create budget → monitor budget**

Savings goals and explainable insights can then extend the core loop.

## Prioritization Principle

A story belongs in the MVP only when it contributes to:
- Core user value
- Product learning
- Trust/safety
- Required measurement
