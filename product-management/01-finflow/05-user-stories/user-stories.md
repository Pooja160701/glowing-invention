# FinFlow — User Stories

> Stories are derived from the FinFlow MVP PRD. They are implementation-planning artifacts, not completed development work.

## EPIC-01 — Onboarding

### US-001 — Create Profile
**As a** new user,  
**I want to** create my FinFlow profile,  
**so that** I can securely access my financial workspace.

**Priority:** P0  
**Requirement:** Product setup

### US-002 — Understand Data Use
**As a** new user,  
**I want to** understand how my financial data will be used,  
**so that** I can make an informed decision before providing data.

**Priority:** P0  
**Requirement:** Privacy by design

---

## EPIC-02 — Transaction Import & Categorization

### US-003 — Import Transactions
**As a** user,  
**I want to** upload supported transaction data,  
**so that** I can avoid manually entering every transaction.

**Priority:** P0  
**Requirement:** FR-001

### US-004 — Review Import Errors
**As a** user,  
**I want to** see which transaction records failed validation,  
**so that** I can correct them without losing the successful records.

**Priority:** P0  
**Requirement:** FR-001

### US-005 — View Categorized Transactions
**As a** user,  
**I want to** see categories assigned to my transactions,  
**so that** I can understand my spending.

**Priority:** P0  
**Requirement:** FR-002

### US-006 — Correct a Category
**As a** user,  
**I want to** change an incorrect transaction category,  
**so that** my financial analysis remains accurate.

**Priority:** P0  
**Requirement:** FR-002

---
