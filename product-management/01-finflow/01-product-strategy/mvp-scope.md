# FinFlow — MVP Scope

## MVP Objective

Validate whether a focused personal-finance workflow can help users move from raw transaction information to understandable financial actions.

## Core User Journey

1. Create profile
2. Import transaction data
3. Review automatically categorized transactions
4. Correct categories when needed
5. View spending breakdown
6. Create a monthly budget
7. Monitor budget progress
8. Create a savings goal
9. Receive relevant insight
10. Return to review progress

## MVP Features

### F1 — Transaction Import
Users can upload supported transaction data.

**Requirement:** Imported records must be validated before entering the user-facing financial view.

### F2 — Transaction Categorization
Transactions receive categories based on available transaction information.

**Requirement:** Users can manually correct categorization.

### F3 — Spending Dashboard
Users can view income, expenses, category distribution, and trends.

### F4 — Budget Tracking
Users can create category budgets and monitor actual versus planned spending.

### F5 — Savings Goals
Users can define a target amount and target date and monitor progress.

### F6 — Financial Insights
The system generates explainable insights based on recent financial activity.

### F7 — Notifications
Users receive meaningful notifications related to budget or goal events.

### F8 — Product Analytics
Core actions are instrumented for funnel, engagement, and retention analysis.

## MVP Non-Goals

- Investment recommendations
- Automated transfers
- Lending decisions
- Credit scoring
- Tax advice
- Insurance recommendations

## MVP Acceptance Principle

A feature is not considered complete because the UI exists. It must have:
- Defined user problem
- Product requirement
- Acceptance criteria
- Analytics instrumentation
- Measurable success metric
- Documented edge cases
