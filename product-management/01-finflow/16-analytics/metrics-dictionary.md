# FinFlow — Metrics Dictionary

## Acquisition
### Visitor-to-Signup Rate
Signups / eligible visitors.

### Signup Completion Rate
Users completing signup / signup starts.

## Activation
### Import Completion Rate
Successful imports / import starts.

### Time to First Financial Action
Median time from onboarding completion to first meaningful financial action.

## Engagement
### WAFAU
Unique users completing at least one meaningful financial action in seven days.

### Weekly Active Users
Unique users with a meaningful product interaction in seven days.

## Quality
### Categorization Correction Rate
Corrected categorized transactions / categorized transactions.

### Import Failure Rate
Failed imports / import starts.

## Retention
### Week-4 Retention
Activated users returning and completing a meaningful action during week four.

## Guardrails
- Notification opt-out rate
- Support/contact rate
- Error rate
- Data deletion requests
- Privacy/security incidents

> Metric definitions are portfolio specifications and should be validated against actual production data before use.
