# FinFlow — Funnel & Retention Specification

## Activation Funnel
1. Signup completed
2. Onboarding completed
3. Import started
4. Import completed
5. Dashboard viewed
6. First financial action

## Funnel Questions
- Where do users abandon onboarding?
- Does import completion predict activation?
- Which first financial action is most common?
- Does faster time-to-value correlate with retention?

## Retention Cohorts
Create cohorts by:
- Signup week
- First financial action week
- Acquisition source
- Platform
- User segment

## Retention Definition
A retained user returns in the selected period and completes at least one meaningful financial action.

Avoid interpreting retention changes without checking acquisition mix, product releases, seasonality, and data-quality changes.
