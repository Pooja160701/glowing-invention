# FinFlow — Experimentation Specification

> All examples are proposed experiments; results must not be presented as observed production results.

## Experiment A — Dashboard First-Action Prompt

**Hypothesis:** A clearer first-action prompt will increase the proportion of activated users completing a meaningful financial action.

**Primary metric:** First financial action rate.

**Secondary metrics:** Time to first action, dashboard engagement.

**Guardrails:** Error rate, notification opt-outs, support contacts.

**Eligibility:** New users completing onboarding.

**Variants:** Control dashboard; treatment dashboard with contextual action prompt.

## Experiment B — Import Progress Feedback

**Hypothesis:** Clearer import progress and completion messaging will reduce import abandonment.

**Primary metric:** Import completion rate.

**Guardrails:** Import errors and support contacts.

## Decision Framework
Define success thresholds before launch, check data quality, analyze by pre-specified segments, and avoid stopping an experiment solely because an early result looks favorable.
