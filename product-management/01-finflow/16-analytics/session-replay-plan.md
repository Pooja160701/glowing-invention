# FinFlow — Session Replay & Qualitative Analytics

## Hotjar / FullStory / PostHog Replay Use Cases

- Identify onboarding friction
- Understand dashboard navigation problems
- Diagnose import errors
- Identify confusing budget interactions
- Investigate rage clicks or repeated actions

## Privacy Controls
- Mask financial amounts
- Mask account identifiers
- Exclude authentication fields
- Exclude bank credentials
- Exclude free-form financial descriptions where feasible
- Restrict replay access by role
- Define retention limits

## Research Workflow
1. Detect quantitative friction.
2. Select a narrow affected flow.
3. Review masked replay/sample sessions.
4. Form a UX hypothesis.
5. Validate with user research.
6. Ship a targeted change.
7. Measure the related product metric.
