# FinFlow — Product Analytics Dashboard Specification

## Executive View
- WAFAU
- Activation rate
- Import completion rate
- First financial action rate
- Week-4 retention
- Categorization correction rate
- Import failure rate

## Acquisition View
- Visitors
- Signups
- Signup conversion
- Source / campaign
- Platform

## Activation View
- Onboarding completion
- Import completion
- Dashboard activation
- First financial action
- Median time to first action

## Engagement View
- WAFAU
- Actions per active user
- Budget usage
- Goal usage
- Insight action rate

## Quality View
- Categorization correction rate
- Import failures
- Error rate
- Support contacts

## Trust & Privacy View
- Notification opt-outs
- Data deletion requests
- Privacy-related feedback
- Security incidents

## Segmentation
Segment by platform, acquisition source, lifecycle stage, and broad non-sensitive user cohort attributes. Do not expose individual financial records in product analytics dashboards.
