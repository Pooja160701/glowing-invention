# FinFlow — Board Configuration

## Delivery Flow
Product Backlog → Ready for Refinement → Ready for Development → In Development → Code Review → QA / Validation → Ready for Release → Released

Blocked work can move to Blocked from any active delivery stage.

## Ready for Development Criteria
- Clear user problem
- User story
- Acceptance criteria
- Priority
- Design requirement identified
- Technical dependency identified
- Analytics requirement identified where relevant

## Released Criteria
- Acceptance criteria passed
- Critical QA scenarios passed
- Analytics events validated
- Documentation updated
- No unresolved release-blocking defect
- Release notes prepared
