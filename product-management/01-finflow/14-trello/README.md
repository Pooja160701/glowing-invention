# FinFlow — Trello Execution Board

> **Status:** Specification / import-ready artifact. No external Trello board was connected or modified.

## Board
**FinFlow — Product Delivery**

## Lists
1. Product Backlog
2. Ready for Refinement
3. Ready for Development
4. In Development
5. Code Review
6. QA / Validation
7. Ready for Release
8. Released
9. Blocked

## Card Design
Every delivery card should contain: problem statement, user story, acceptance criteria, priority, product area, owner, dependencies, target release, and Definition of Done.

## Labels
P0 — Critical; P1 — High; P2 — Medium; Discovery; Product; Design; Engineering; Data; Analytics; Security; QA.

## WIP Rules
- In Development: maximum 3 cards per team
- QA / Validation: maximum 3 cards
- Blocked cards must include a blocker and next action

Trello represents execution flow; strategy, research, and long-form requirements remain in their dedicated artifacts.
