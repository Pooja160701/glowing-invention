# FinFlow — Launch Metrics

## North Star
**WAFAU — Weekly Active Financial Action Users**

## Launch KPI Set

### Activation
- Signup completion
- Onboarding completion
- Import completion
- First financial action
- Time to first action

### Engagement
- WAFAU
- Budget usage
- Goal usage
- Insight action rate

### Quality
- Import failure rate
- Categorization correction rate
- Error rate

### Retention
- Week-1 retention
- Week-4 retention

### Trust / Guardrails
- Notification opt-out rate
- Support contact rate
- Privacy-related feedback
- Data deletion requests
- Security incidents

Metrics should be reviewed by cohort and release version where appropriate.
