# FinFlow — Feedback & Learning Loop

## Sources
- In-product feedback
- Support contacts
- Usability research
- Session replay insights
- Product analytics
- Surveys
- User interviews

## Synthesis Process
1. Collect
2. Deduplicate
3. Tag by theme
4. Assess frequency and severity
5. Connect to affected user segment
6. Validate against behavioral evidence
7. Create opportunity
8. Prioritize
9. Ship
10. Measure

## Feedback Record

```text
Source:
User segment:
Problem:
Evidence:
Frequency:
Severity:
Current workaround:
Opportunity:
Metric affected:
Proposed next step:
```

Feedback should inform product decisions but should not automatically become a feature request without problem validation.
