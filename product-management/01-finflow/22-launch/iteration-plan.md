# FinFlow — Iteration Plan

## Iteration Loop

```text
Launch
 ↓
Measure
 ↓
Identify friction
 ↓
Research
 ↓
Prioritize
 ↓
Experiment / Build
 ↓
Release
 ↓
Measure again
```

## Priority Categories

### Reliability
Fix issues that compromise data integrity, privacy, security, or core availability.

### Activation
Reduce friction before the first meaningful financial action.

### Engagement
Improve budget, goal, and insight workflows where evidence supports the opportunity.

### Trust
Improve explanations, controls, and transparency.

### Expansion
Consider advanced capabilities only after the core product loop is demonstrably useful.

## Roadmap Feedback Rule
Every major roadmap addition should identify the user problem, evidence, expected outcome, dependencies, and measurement plan.
