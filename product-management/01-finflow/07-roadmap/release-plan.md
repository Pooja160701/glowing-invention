# FinFlow — Release Plan

## Release 0.1 — Internal Product Slice

### Goal
Validate the end-to-end technical and product workflow.

### Included
- Basic onboarding
- Transaction import
- Transaction list
- Basic categorization
- Basic dashboard

### Exit Criteria
- Core flow works end-to-end
- Critical calculations pass QA
- Core analytics events are captured

---

## Release 0.2 — MVP Beta

### Goal
Validate budget-management value.

### Included
- Budget creation
- Budget monitoring
- Category correction
- Privacy/data controls
- Improved dashboard

### Exit Criteria
- Target user journey is testable
- Critical acceptance criteria pass
- Import and dashboard workflows are stable
- Key activation metrics are measurable

---

## Release 0.3 — Financial Wellness Beta

### Goal
Validate whether users find goals and insights useful.

### Included
- Savings goals
- Explainable insights
- Insight feedback
- Recurring-expense candidates

### Exit Criteria
- Goal workflow passes QA
- Insight explanations are understandable
- Insight feedback is measurable
- No critical privacy/security issues

---

## Release 1.0 — Product Launch Candidate

### Goal
Provide a stable core financial-wellness experience.

### Included
- MVP functionality
- Analytics
- Notification controls
- Reliability improvements
- Documentation
- Launch support

### Launch Readiness
- Product acceptance complete
- Security/privacy review complete
- Critical defects resolved
- Monitoring available
- Support/feedback process defined
