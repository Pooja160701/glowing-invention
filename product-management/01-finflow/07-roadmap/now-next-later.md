# FinFlow — Now / Next / Later

## NOW — Prove the Core Loop

### Initiative N1 — Reliable Financial Data
- Transaction import
- Validation
- Categorization
- Category correction

**Outcome:** Users can establish a trustworthy financial dataset.

### Initiative N2 — Financial Clarity
- Dashboard
- Spending categories
- Cash-flow summary

**Outcome:** Users can understand their current financial position.

### Initiative N3 — Budget Control
- Budget creation
- Budget monitoring
- Budget status

**Outcome:** Users can plan and monitor spending.

### Initiative N4 — Measurement Foundation
- Core event instrumentation
- Funnel tracking
- Error monitoring

**Outcome:** Product decisions can be based on measurable behavior.

---

## NEXT — Build Financial Wellness

### Initiative X1 — Savings Goals
Connect user goals with measurable progress.

### Initiative X2 — Explainable Insights
Surface relevant patterns with transparent reasoning.

### Initiative X3 — Recurring Expenses
Help users identify repeated spending.

### Initiative X4 — Feedback Loops
Capture insight relevance and user corrections.

---

## LATER — Expand the Platform

### Initiative L1 — Account Connectivity
Explore direct financial-account connections.

### Initiative L2 — Advanced Forecasting
Evaluate future cash-flow scenarios.

### Initiative L3 — Household Finance
Explore shared financial planning.

### Initiative L4 — Scenario Planning
Allow users to model financial decisions.

## Prioritization Rule

Later initiatives should not displace core usability, trust, privacy, or reliability work without evidence supporting the tradeoff.
