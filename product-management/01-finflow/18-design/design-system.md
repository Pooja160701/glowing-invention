# FinFlow — Design System Notes

## Visual Direction
Calm, clear, trustworthy, and information-first.

## Typography
Use a highly legible sans-serif typeface with clear hierarchy.

### Suggested Scale
- Display: 32px
- H1: 28px
- H2: 22px
- H3: 18px
- Body: 16px
- Supporting: 14px

## Spacing
Use an 8px base spacing system.

## Components
- Primary button
- Secondary button
- Text field
- Select
- Progress bar
- Metric card
- Insight card
- Transaction row
- Budget row
- Goal card
- Alert
- Empty state
- Error state
- Confirmation message

## Accessibility
- Keyboard navigable interactions
- Visible focus states
- Text alternatives for meaningful icons
- Sufficient contrast
- Do not rely on color alone
- Clear error messages
- Minimum comfortable touch target sizing

## Financial Data Safety
Avoid visual patterns that expose sensitive values unnecessarily. Mask sensitive identifiers and provide clear privacy controls.
