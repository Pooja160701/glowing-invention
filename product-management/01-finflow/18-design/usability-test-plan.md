# FinFlow — Usability Test Plan

> Proposed test plan. Results should be added only after actual sessions.

## Participants
5–8 representative target users for an initial usability round.

## Tasks
1. Explain what FinFlow does.
2. Complete onboarding.
3. Import sample transactions.
4. Find a spending category.
5. Correct a category.
6. Create a budget.
7. Find a savings goal.
8. Explain why an insight appeared.

## Measures
- Task completion
- Time on task
- Critical errors
- Assistance required
- Confidence rating
- Qualitative comments

## Success Criteria
Define task-level thresholds before testing. Do not convert a small qualitative sample into population-level claims.

## Follow-up
Synthesize findings into severity-ranked UX issues and map each issue to a product requirement or design change.
