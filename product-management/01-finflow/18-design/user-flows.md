# FinFlow — User Flows

## Flow 1 — First-Time Activation

Landing
→ Sign up
→ Privacy explanation
→ Onboarding preferences
→ Import data
→ Import confirmation
→ Dashboard
→ First financial action

### Success
User reaches a useful financial action without manual data-entry overload.

## Flow 2 — Categorization Correction

Dashboard
→ Transactions
→ Select transaction
→ Edit category
→ Save
→ Updated totals
→ Confirmation

### Success
The corrected category persists and downstream views update consistently.

## Flow 3 — Budget Creation

Dashboard
→ Budget
→ Create budget
→ Select period
→ Select categories
→ Set limits
→ Review
→ Save
→ Budget progress

## Flow 4 — Savings Goal

Dashboard
→ Goals
→ Create goal
→ Select goal type
→ Define target range
→ Choose target date
→ Review
→ Save
→ Progress view

## Flow 5 — Insight Action

Dashboard
→ Insight card
→ Why this insight?
→ Evidence / explanation
→ Recommended action
→ User action
→ Confirmation
