# FinFlow — Clickable Prototype Specification

## Prototype Scope
Create a 10–12 screen clickable prototype covering the critical MVP journey.

### Screen Map
1. Welcome
2. Privacy & data controls
3. Onboarding preferences
4. Import
5. Import success
6. Dashboard
7. Transactions
8. Category correction
9. Budget
10. Savings goal
11. Insight explanation
12. Notification preferences

## Prototype Links
- Welcome → Privacy
- Privacy → Onboarding
- Onboarding → Import
- Import → Success
- Success → Dashboard
- Dashboard → Transactions
- Transactions → Correction
- Dashboard → Budget
- Dashboard → Goal
- Dashboard → Insight
- Dashboard → Notification settings

## Prototype Validation Questions
- Can users understand the value proposition immediately?
- Do users understand why financial data is requested?
- Can users complete the import flow without assistance?
- Can users identify what action to take on the dashboard?
- Can users understand an insight without trusting a black box?
