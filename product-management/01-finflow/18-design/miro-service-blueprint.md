# FinFlow — Miro Service Blueprint

## User Actions
Sign up → Import → Review → Plan → Monitor → Act

## Frontstage
- Onboarding
- Import feedback
- Dashboard
- Budget status
- Goal progress
- Insight explanation

## Backstage
- Authentication
- Import processing
- Categorization
- Aggregation
- Insight generation
- Notification service

## Data / Systems
- User profile
- Transaction store
- Category service
- Budget service
- Goal service
- Analytics pipeline

## Support
- Help center
- Feedback collection
- Incident handling

## Key Failure Points
- Import failure
- Incorrect category
- Stale dashboard
- Unexplained insight
- Notification overload

## Design Opportunity
Expose meaningful system status and recovery paths instead of leaving users uncertain about what happened.
