## Design Goal
Make personal financial management understandable, trustworthy, and action-oriented without overwhelming users.

## Core Flow
Onboarding → Import → Categorize → Dashboard → Budget / Goal → Insight → Action

## Design Principles
1. Explain before asking users to act.
2. Show financial information progressively.
3. Make correction easy.
4. Avoid unnecessary financial-data exposure.
5. Design for accessibility and calm decision-making.
