# FinFlow — Product Metrics

## North Star Metric

**Weekly Active Financial Action Users (WAFAU)**

A WAFAU is an active user who completes at least one meaningful financial-management action in a week, such as:
- Reviewing categorized transactions
- Creating/editing a budget
- Contributing to a goal
- Acting on an insight

## Activation Metrics

| Metric | Definition |
|---|---|
| Import completion rate | Users completing first successful transaction import / users starting import |
| First dashboard completion | Users reaching populated dashboard / activated users |
| Budget creation rate | Activated users creating a budget |
| Goal creation rate | Activated users creating a goal |

## Engagement Metrics

| Metric | Definition |
|---|---|
| Weekly active users | Users with at least one qualifying product session/action |
| Insight engagement rate | Insight interactions / insights displayed |
| Budget monitoring rate | Users viewing budget status / users with budgets |
| Goal monitoring rate | Users viewing goal progress / users with goals |

## Quality Metrics

| Metric | Definition |
|---|---|
| Categorization correction rate | Manually corrected categorized transactions / categorized transactions |
| Import failure rate | Failed imports / import attempts |
| Insight dismissal rate | Dismissed insights / displayed insights |
| Notification opt-out rate | Users disabling notification category / users exposed to it |

## Guardrail Metrics

- Support/contact rate
- Data deletion requests
- Privacy-control interactions
- Error rate
- Notification complaints
- Security incidents

## Measurement Principle

No metric should be interpreted without its denominator, time period, segment, and product context.
