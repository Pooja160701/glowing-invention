# FinFlow — Scope & Non-Goals

## MVP In Scope

### User Experience
- Onboarding
- Transaction import
- Transaction review
- Dashboard
- Budgets
- Savings goals
- Financial insights
- Notification preferences

### Data
- Transaction records
- Categories
- Budgets
- Goals
- Insight events
- Product analytics events

### Platform
- Authentication
- Authorization
- Auditability
- Error handling
- Analytics instrumentation

## Explicit Non-Goals

The MVP will not:
- Execute bank transfers
- Buy or sell investments
- Approve loans
- Generate credit scores
- File taxes
- Provide regulated financial advice
- Automatically move money
- Sell user financial data

## Future Opportunities

- Direct account connections
- Advanced forecasting
- Household finance
- Subscription management
- Scenario planning
- Personalized financial education

Each future opportunity requires separate validation and risk assessment.
