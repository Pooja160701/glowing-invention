# FinFlow — Product HQ

## Mission
Help users understand their finances and take useful financial-management actions with less effort.

## Current Stage
Portfolio MVP planning.

## Product Loop
**Import → Understand → Plan → Monitor → Act**

## Current Focus

### 1. Financial Data Foundation
Build trustworthy transaction ingestion and categorization.

### 2. Financial Clarity
Create a simple dashboard that explains the user's financial position.

### 3. Budget Control
Enable users to plan and monitor spending.

### 4. Financial Wellness
Add goals and explainable insights after the core data loop is reliable.
