**Project Key:** FINFLOW

**Project Type:** Software / Agile Scrum

## Workflow

**Backlog → Selected for Development → In Progress → Code Review → QA → Ready for Release → Done**

Blocked work should use a visible **Blocked** flag/status convention rather than silently remaining In Progress.

## Jira Usage Principle

Jira should represent execution of the product strategy rather than becoming a duplicate copy of the PRD. Product requirements live in the PRD; Jira tracks delivery work.
