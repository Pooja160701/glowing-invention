# FinFlow — Jira Sprint Plan

> **Status:** Proposed planning simulation.

## Sprint 1 — Establish the Core

### Goal
Create a secure starting point and prove transaction ingestion.

### Planned Work
- FIN-101 Create user profile
- FIN-102 Explain financial data use
- FIN-103 Import transaction file
- FIN-104 Display import validation errors
- FIN-119 Instrument core product events
- FIN-121 Provide data controls

### Sprint Outcome
A user can establish a workspace, understand data usage, import data, and begin using the product with core instrumentation.

---

## Sprint 2 — Understand Money

### Goal
Turn transaction data into usable financial information.

### Planned Work
- FIN-105 Display categorized transactions
- FIN-106 Correct transaction category
- FIN-107 Display financial summary
- FIN-108 Explore spending categories
- FIN-122 Support financial data deletion request

### Sprint Outcome
Users can review and correct transactions and understand spending.

---

## Sprint 3 — Budget Control

### Goal
Introduce the core planning workflow.

### Planned Work
- FIN-109 Create category budget
- FIN-110 Monitor budget progress
- FIN-111 Edit category budget

### Sprint Outcome
Users can create and monitor budgets.

---

## Sprint 4 — Financial Wellness

### Goal
Connect financial behavior to goals and insights.

### Planned Work
- FIN-112 Create savings goal
- FIN-113 View goal progress
- FIN-114 Display financial insight
- FIN-115 Explain financial insight

### Sprint Outcome
Users can track goals and understand relevant financial insights.

---

## Sprint 5 — Engagement

### Goal
Improve the product's action loop without increasing notification fatigue.

### Planned Work
- FIN-116 Act on financial insight
- FIN-117 Configure notification preferences
- FIN-118 Send budget threshold notification
- FIN-120 Track insight feedback

### Sprint Outcome
Users can act on useful insights and control how the product communicates with them.
