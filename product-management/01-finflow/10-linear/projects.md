# FinFlow — Linear Projects

## Project 1 — Transaction Foundation
**Initiative:** Financial Clarity
**Goal:** Create reliable transaction ingestion and categorization.
**Deliverables:** Import validation, transaction persistence, categorization, correction, error handling.

## Project 2 — Financial Dashboard
**Initiative:** Financial Clarity
**Goal:** Give users a clear view of financial position.
**Deliverables:** Income/expense summary, net cash flow, category spending, time filters, empty/error states.

## Project 3 — Budget & Goals
**Initiative:** Budget & Goal Management
**Goal:** Enable planning and progress monitoring.
**Deliverables:** Budgets, monitoring, editing, savings goals, goal progress.

## Project 4 — Insights & Engagement
**Initiative:** Actionable Financial Insights
**Goal:** Provide useful and explainable financial insights.
**Deliverables:** Eligibility, display, explanations, actions, feedback, notification preferences.

## Project 5 — Analytics & Trust
**Initiative:** Trust, Privacy & Measurement
**Goal:** Establish measurement, privacy, and trust foundations.
**Deliverables:** Event schema, data controls, deletion workflow, notification preferences, observability.
