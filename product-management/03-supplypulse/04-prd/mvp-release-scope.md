# SupplyPulse MVP Release Scope

## P0 — Controlled pilot
### Inventory
- SKU/location inventory view
- inventory status and value
- freshness/source indicators
- basic aging

### Supply and demand
- demand history/input
- forecast input
- open PO and expected receipt
- lead-time context

### Exceptions
- stockout risk
- excess/aging
- late PO
- lead-time deviation
- data-quality exception
- prioritized queue
- owner/status/due date

### Replenishment
- reorder recommendation
- rationale
- approve/edit/reject
- audit trail

### Supplier risk
- supplier performance
- affected PO/SKU context
- receipt-risk visibility

### Governance
- RBAC
- audit logs
- data-quality status
- integration health

## P1
- advanced executive dashboards
- configurable exception rules
- configurable approval policies
- richer supplier analytics
- richer workflow notifications

## P2
- multi-echelon optimization
- scenario simulation
- autonomous low-risk replenishment
- supplier collaboration portal
- advanced ML forecasting

## Pilot boundaries
- limited organizations
- defined SKU/location scope
- controlled integrations
- human approval for material actions
- explicit rollback procedures
