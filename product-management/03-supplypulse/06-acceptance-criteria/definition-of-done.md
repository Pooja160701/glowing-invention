# SupplyPulse Definition of Done

## Product
- Story intent is satisfied.
- Acceptance criteria are all demonstrated.
- Product owner has reviewed the behavior.
- Edge cases relevant to the workflow are covered.

## Engineering
- Code reviewed.
- Unit/integration tests pass.
- Error handling implemented.
- Logging and observability added where appropriate.
- Configuration and secrets are externalized.

## Data
- Source ownership documented.
- Schema validation implemented.
- Freshness behavior tested.
- Lineage available for decision-critical data.
- Synthetic demo data remains explicitly labeled.

## Security
- Authorization enforced server-side.
- Sensitive data handling reviewed.
- Audit requirements implemented for material actions.
- No credentials or secrets committed.

## Analytics
- Required product events implemented.
- Event properties validated.
- Core funnel and operational metrics available.
- Dashboard definitions documented.

## QA
- Acceptance criteria pass.
- Positive, negative, and edge scenarios tested.
- Regression suite updated.
- No unresolved critical/high-severity defects.

## Release
- Documentation updated.
- Rollback plan documented.
- Monitoring configured.
- Support/runbook information available.
- Release notes prepared.
