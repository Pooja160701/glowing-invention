# SupplyPulse UX Design System Specification

## Visual direction
Operational, calm, information-dense, and trustworthy.

## Layout
- 12-column desktop grid.
- Responsive behavior for tablet.
- Consistent content max-width.
- Persistent left navigation on desktop.

## Core components
- App shell
- Navigation
- KPI card
- Status badge
- Severity indicator
- Data freshness badge
- Exception row
- Filter bar
- Data table
- Detail panel
- Timeline
- Recommendation card
- Approval control
- Audit event
- Empty state
- Error state
- Degraded-data banner
- Confirmation dialog

## Severity model
Use explicit labels: Critical, High, Medium, Low, Informational.
Avoid relying only on red/amber/green color.

## Trust patterns
Every decision-critical data card should make it easy to find source, last updated, and quality state.
