# SupplyPulse UX User Flows

## Flow 1 — Daily exception review
Home → Priority exceptions → Exception detail → Context → Assign/accept → Action → Resolve → Resolution evidence

## Flow 2 — Replenishment
Exception / Replenishment → Recommendation → Rationale → Input details → Approve / Edit / Reject → Audit confirmation

## Flow 3 — Supplier delay
Home → Late PO exception → Supplier context → Affected inventory → Risk assessment → Supplier action → Resolution

## Flow 4 — Data-quality issue
Home → Data-quality warning → Affected record → Source/lineage → Investigate → Source correction → Refresh → Resolve

## Flow 5 — Executive review
Home → KPI summary → Risk trend → Exception cluster → Drill-down → Owner/action status

## Flow 6 — First-time user
Sign in → Role detection → Guided orientation → Priority queue → Open first exception → Context explanation → Complete first action

## Flow principle
Every critical flow should minimize context switching and preserve the user's place in the exception workflow.
