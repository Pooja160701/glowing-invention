# SupplyPulse Accessibility Specification

## Target
WCAG 2.2 AA for applicable user-facing workflows.

## Keyboard
- All interactive controls keyboard reachable.
- Logical focus order.
- Visible focus indicator.
- No keyboard traps.

## Screen readers
- Semantic headings.
- Accessible names for controls.
- Table headers and relationships.
- Status changes announced appropriately.

## Color
Do not communicate severity by color alone. Use text labels, icons, and supporting indicators.

## Tables
- sortable columns have accessible labels
- filters are clearly identified
- row actions are keyboard accessible
- pagination/state is announced

## Charts
Every important chart has a text summary or accessible data representation.

## Forms
- labels are persistent
- validation errors identify the field
- error messages explain corrective action
- required fields are programmatically identified

## Time-sensitive states
Users should have enough time to review decisions; automatic refresh must not unexpectedly discard unsaved work.
