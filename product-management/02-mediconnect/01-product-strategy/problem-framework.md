# MediConnect — Problem → User → Requirement → Outcome

| Problem | User | Requirement | Product Capability | Metric | Outcome |
|---|---|---|---|---|---|
| Appointment discovery is fragmented | Patient | Show relevant availability | Provider search | Search-to-book conversion | Easier access |
| Booking requires repeated coordination | Patient | Reserve an available slot | Appointment booking | Booking completion | Lower friction |
| Changes create phone/email overhead | Patient + Staff | Self-service changes | Reschedule/cancel | Change success rate | Lower admin effort |
| Patients forget appointments | Patient | Deliver timely reminders | Reminder service | Reminder delivery/engagement | Fewer avoidable missed appointments |
| Schedule conflicts create operational work | Staff | Enforce availability rules | Scheduling engine | Conflict rate | Better schedule reliability |
| Sensitive information can be mishandled | Patient + Provider | Restrict access | RBAC + audit logs | Security/privacy incidents | Greater trust |
| Staff cannot see workflow bottlenecks | Staff | Operational reporting | Staff dashboard | Resolution time | Better operations |
