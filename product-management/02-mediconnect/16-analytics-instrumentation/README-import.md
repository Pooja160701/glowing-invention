# Analytics Implementation Checklist

## Before development
- [ ] Event taxonomy approved.
- [ ] Tracking plan linked to product questions.
- [ ] Data classification reviewed.
- [ ] Identity strategy approved.
- [ ] Analytics ownership assigned.

## During development
- [ ] P0 events implemented.
- [ ] Required properties validated.
- [ ] Duplicate handling implemented.
- [ ] Error paths instrumented.

## Before release
- [ ] QA contract tests pass.
- [ ] Source-of-truth reconciliation passes.
- [ ] Privacy scan passes.
- [ ] Dashboards validated.
- [ ] Documentation versioned.

## After release
- [ ] Monitor event volume.
- [ ] Monitor schema violations.
- [ ] Monitor reconciliation variance.
- [ ] Review funnel movement.
- [ ] Feed validated findings into roadmap decisions.
