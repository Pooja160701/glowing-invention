# MediConnect — Experimentation

**Status:** Portfolio-ready specification  
**Results in this folder are synthetic unless explicitly marked otherwise.**

This layer defines a controlled experimentation framework for improving the MediConnect administrative care journey.

## Experiment principles

- Every experiment starts with a product question.
- Hypotheses are measurable and falsifiable.
- Primary metrics are defined before launch.
- Guardrail metrics protect reliability, privacy, and user experience.
- Experiments must respect healthcare privacy and product scope.
- Synthetic results must never be presented as production evidence.

## Primary product outcome

**Completed Care Journey Rate (CCJR)**

Use CCJR alongside funnel, reliability, communication, and operational guardrails.
