# Trello Import Guide

## Recommended setup

Create one board:
MediConnect — Product Delivery

Create lists in this order:
1. Product Backlog
2. Ready for Development
3. In Progress
4. Code Review
5. QA / Validation
6. Ready for Release
7. Released
8. Blocked / Needs Decision

## Card creation
Use sample-board.csv as the source for the initial portfolio board.

Map:
- Card Title → Card name
- List → List
- Priority → Label
- Labels → Labels
- Release → Custom field or description
- Owner → Member
- Points → Custom field
- Dependency → Description
- Metric → Description

## Label taxonomy
Keep labels stable across the board. Avoid creating a new label for every feature.

## Important
This repository does not claim that a Trello workspace, cards, or automations were actually created. These artifacts are implementation-ready specifications for a real workspace.
