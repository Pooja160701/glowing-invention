# Trello Card Templates

## Feature card
Title: [AREA] Feature — Outcome

Description:
- Problem:
- User/persona:
- Desired outcome:
- Requirement:
- User story:
- Acceptance criteria:
- Dependencies:
- Metrics:
- Design:
- Technical notes:

Definition of Ready:
- [ ] Problem understood
- [ ] User story approved
- [ ] Acceptance criteria complete
- [ ] Dependencies identified
- [ ] Design available if needed
- [ ] Analytics requirements identified

Definition of Done:
- [ ] Implemented
- [ ] Code reviewed
- [ ] QA passed
- [ ] Security/privacy checks passed where applicable
- [ ] Analytics verified
- [ ] Documentation updated
- [ ] Release notes prepared
