# Metric Ownership

| Area | Primary owner | Supporting owner | Review |
|---|---|---|---|
| CCJR | Product | Data, Operations | Weekly |
| Booking | Product | Engineering, QA | Daily/weekly |
| Discovery | Product | Design, Data | Weekly |
| Self-service | Product | Design, Engineering | Weekly |
| Communications | Operations | Engineering, Data | Daily |
| Scheduling integrity | Engineering | Product, QA | Daily |
| Exceptions | Operations | Product | Daily |
| Security | Security | Engineering | Daily |
| Privacy | Privacy | Data/Product | Daily |
| Analytics quality | Data | Engineering, Product | Daily |
| BI reporting | Data/Product | BI | Weekly |

## Ownership rules

The owner is responsible for:
- Metric definition.
- Data-quality checks.
- Threshold proposal.
- Alert response.
- Root-cause investigation.
- Reporting consistency.
- Documentation updates.

Ownership does not mean the team alone controls the metric. Cross-functional drivers should be documented.
