# Product Health Scorecard

## Dimensions

### 1. Access
Measures whether patients can find and book viable appointments.

Inputs:
- Search-to-book conversion.
- Availability success.
- Booking success.

### 2. Reliability
Measures whether core scheduling workflows operate correctly.

Inputs:
- Core scheduling availability.
- Slot mismatch.
- Duplicate booking rate.
- API error rate.

### 3. Self-service
Measures whether patients can manage appointments independently.

Inputs:
- Cancellation completion.
- Reschedule completion.
- Self-service abandonment.

### 4. Communications
Measures whether reminders and preference workflows work reliably.

Inputs:
- Notification delivery.
- Notification failure.
- Delivery latency.

### 5. Operations
Measures staff recovery and workflow efficiency.

Inputs:
- Exception volume.
- Median resolution time.
- Critical unresolved exceptions.

### 6. Trust
Measures security and privacy posture.

Inputs:
- Authorization failures.
- Audit coverage.
- Privacy violations.

## Health interpretation

Use status categories:
- Healthy
- Watch
- Action required
- Critical

The status should be determined from documented thresholds and context, not subjective scoring.

## Executive review

Review dimensions together rather than optimizing a single KPI in isolation.
