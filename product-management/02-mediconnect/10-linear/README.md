# MediConnect — Linear Planning Specification

**Status:** Portfolio-ready specification  
**External Linear workspace:** Not connected or created

This folder demonstrates how MediConnect could be managed in Linear using outcome-oriented initiatives, projects, cycles, and issues.

## Hierarchy

**Initiative → Project → Cycle → Issue**

## Planning model

- Initiatives represent measurable product outcomes.
- Projects represent bounded delivery programs.
- Cycles represent short execution windows.
- Issues represent executable work.
