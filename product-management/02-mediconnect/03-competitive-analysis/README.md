# MediConnect — Competitive Analysis

**Artifact status:** Portfolio specification informed by public competitor information reviewed in October 2026.

This layer evaluates the appointment access, scheduling, patient engagement, and provider-operations landscape around MediConnect.

## Competitor set

- **Zocdoc** — healthcare discovery, real-time booking, provider growth and scheduling infrastructure.
- **Practo** — India-focused healthcare discovery, appointment booking, consultation, records, and provider software.
- **Doctolib** — healthcare booking and practice operating capabilities with patient communication and care-journey features.
- **Epic / MyChart** — health-system/EHR ecosystem with patient self-scheduling, centralized scheduling, communications, and integrated workflows.

## Analysis boundary

This is a product-management comparison, not a clinical-quality ranking. It focuses on observable product capabilities and workflow design.

**Important:** Competitor capabilities change. Claims in this folder should be revalidated before using them as current market facts.
