# MediConnect — Jobs To Be Done

## Patient JTBDs

### JTBD-01 — Find Care
When I need an appointment, I want to see relevant providers and real availability so I can choose a suitable option confidently.

### JTBD-02 — Book Care
When I find a suitable slot, I want to confirm it quickly so I do not need repeated coordination.

### JTBD-03 — Change Care
When my plans change, I want to reschedule or cancel easily so I can avoid unnecessary calls and uncertainty.

### JTBD-04 — Remember Care
When an appointment is approaching, I want a useful reminder through a channel I control so I can prepare and attend.

### JTBD-05 — Review Care History
When I need to remember past appointments, I want one reliable history so I do not search across messages and emails.

## Staff JTBDs

### JTBD-06 — Maintain Availability
When provider schedules change, I want availability to stay accurate so patients do not book invalid slots.

### JTBD-07 — Resolve Exceptions
When cancellations or conflicts occur, I want one operational view so I can resolve them quickly.

### JTBD-08 — Manage Communication
When appointment messages are sent, I want delivery status so I know whether follow-up is required.
