# MediConnect — User Personas

## Persona 1 — The Time-Constrained Patient

**Context:** Working adult managing healthcare around a busy schedule.

**Goals**
- Find a suitable appointment quickly.
- Know that the slot is actually available.
- Change appointments without calling.
- Receive useful reminders.

**Frustrations**
- Unclear availability
- Repeated calls
- Uncertain confirmation
- Poor notification timing

**Needs**
- Transparent availability
- Fast booking
- Self-service changes
- Notification controls

---

## Persona 2 — The Clinic Coordinator

**Context:** Front-desk or scheduling staff managing daily appointment operations.

**Goals**
- Maintain accurate schedules.
- Resolve conflicts quickly.
- Reduce repetitive patient communication.
- See operational exceptions.

**Frustrations**
- Manual schedule reconciliation
- Cross-channel changes
- Limited delivery visibility
- Repetitive calls

**Needs**
- Schedule controls
- Exception queue
- Communication status
- Operational reporting

---

## Persona 3 — The Provider Stakeholder

**Context:** Clinician responsible for delivering scheduled care while relying on accurate administrative workflows.

**Goals**
- Trust schedule accuracy.
- Minimize administrative interruptions.
- See relevant appointment context.

**Frustrations**
- Stale availability
- Last-minute changes
- Schedule conflicts

**Needs**
- Reliable schedule state
- Clear exceptions
- Controlled notifications
