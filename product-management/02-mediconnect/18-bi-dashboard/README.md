# MediConnect — BI Dashboard

**Status:** Portfolio-ready specification  
**Data in this folder is synthetic unless explicitly marked otherwise.**

This layer defines the business-intelligence reporting model for MediConnect.

## Dashboard suite

1. Executive Product Dashboard
2. Patient Booking Funnel
3. Scheduling & Operations Dashboard
4. Communications Reliability Dashboard
5. Security & Governance Dashboard

## BI targets

The model is designed to be implemented in:
- Power BI
- Tableau
- Looker
- Metabase

The semantic metric definitions remain consistent across tools.

## Primary outcome

**Completed Care Journey Rate (CCJR)**

CCJR is an administrative product outcome and is not a clinical outcome.
