# Productboard Prioritization

**Important:** Scores are illustrative planning values for portfolio demonstration. They are not market measurements.

## Scoring model

- **User Value (UV):** 1–5
- **Business/Operational Value (BV):** 1–5
- **Strategic Alignment (SA):** 1–5
- **Confidence (CF):** 1–5
- **Effort (EF):** 1–5, where 5 is highest effort

### Illustrative prioritization index

`Priority Index = (UV + BV + SA + CF) / EF`

This is a decision aid, not a mathematical truth.
