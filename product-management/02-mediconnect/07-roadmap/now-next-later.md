# Now / Next / Later

## NOW — Prove the core journey

**Outcome:** Reliable appointment access.

- Patient authentication.
- Provider discovery.
- Availability.
- Slot validation.
- Booking.
- Confirmation.
- Staff availability.
- Core analytics.
- Security/privacy foundation.

**Primary question:** Can patients reliably complete booking without avoidable staff intervention?

---

## NEXT — Improve post-booking experience

**Outcome:** Reduce administrative friction after booking.

- Cancellation.
- Rescheduling.
- Appointment history.
- Reminders.
- Communication preferences.
- Notification status.
- Exception queue.
- Operational metrics.

**Primary question:** Can routine appointment changes and communication failures be resolved without excessive manual work?

---

## LATER — Expand workflow depth

**Outcome:** Support more complex organizations and workflows.

- Secure administrative messaging.
- Advanced scheduling.
- Multi-location administration.
- External scheduling integrations.
- EHR/practice-management integrations.
- Expanded analytics.
- Enterprise controls.

**Primary question:** Which additional capabilities produce validated value after the core workflow is reliable?

---

## Roadmap decision rule

A roadmap item moves from Later to Next only when:

1. A validated user problem exists.
2. Evidence supports meaningful value.
3. Dependencies are understood.
4. Privacy/security implications are acceptable.
5. The organization can operate the resulting workflow.
6. Success can be measured.
