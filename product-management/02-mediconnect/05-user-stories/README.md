# MediConnect — User Stories

**Status:** Portfolio-ready backlog specification  
**Source:** MediConnect PRD v1.0

This layer translates product requirements into Agile epics and user stories.

## Structure

- `epics.md` — epic definitions and outcomes
- `user-stories.md` — detailed user stories
- `story-mapping.md` — backbone and release story map
- `backlog.csv` — import-ready backlog

All stories are written from a user or system actor perspective and should be refined with Engineering, Design, QA, Security, and Operations before implementation.
