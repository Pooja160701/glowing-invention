# Support-to-Product Feedback Loop

## Intake

Support captures:
- Workflow.
- Severity.
- User role.
- Error category.
- Timestamp.
- Organization.
- Correlation ID when available.
- Resolution.

Avoid unnecessary clinical information.

## Triage

### Critical
Immediate product/security/operations escalation.

### High
Review within the operating cadence and link to an owner.

### Medium
Cluster with related feedback.

### Low
Retain for trend analysis.

## Weekly process

1. Export or summarize support themes.
2. Deduplicate.
3. Tag using feedback taxonomy.
4. Identify repeated patterns.
5. Compare against analytics.
6. Create product insights.
7. Link insights to experiments/backlog.
8. Close the loop with support.

## Closed-loop requirement

Every high-confidence product insight should link to:
- Evidence.
- Product decision.
- Backlog item or experiment.
- Outcome metric.

## Feedback-to-release loop

Support issue
→ Insight
→ Product decision
→ Backlog
→ Delivery
→ Measurement
→ Feedback review
