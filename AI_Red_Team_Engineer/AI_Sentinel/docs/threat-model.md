# Threat Model

## Assets
System instructions, hidden context, tool permissions, local files, database actions, external API boundaries, dependencies, build artifacts and audit records.

## Threats
Prompt injection, jailbreak pressure, data leakage, unauthorized tools, unsafe shell execution, path traversal, hard-coded secrets, risky containers and weak dependency hygiene.

## Controls
Least privilege, tool allowlists, human approval, filesystem sandboxing, constrained shell, audit logs, kill switch and static scanning.
