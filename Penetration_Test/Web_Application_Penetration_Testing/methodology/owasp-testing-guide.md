# OWASP-Aligned Methodology

The assessment follows an OWASP-oriented workflow:

1. Information gathering
2. Configuration and deployment review
3. Identity management testing
4. Authentication testing
5. Authorization testing
6. Session management testing
7. Input validation testing
8. Error handling testing
9. Cryptographic review where applicable
10. Business logic testing
11. Client-side testing
12. API testing
13. Reporting and remediation

Automated scanners support the assessment but do not replace manual verification.
