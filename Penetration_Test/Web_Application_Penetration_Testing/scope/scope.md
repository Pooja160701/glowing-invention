# Assessment Scope

## Authorized Target
Application: OWASP Juice Shop
Environment: Local Docker laboratory
Base URL: http://localhost:3000

## In Scope
- Local HTTP application behavior.
- Routes, parameters, forms, APIs, cookies, sessions, and access-control boundaries.
- Nmap enumeration of the local service.
- Burp Suite and OWASP ZAP testing.
- SQL injection validation with SQLmap.
- Security-header and configuration review.
- Evidence and remediation analysis.

## Out of Scope
- Public websites or third-party infrastructure.
- Production systems.
- Real credentials or personal information.
- Denial-of-service testing.
- Persistence, malware, or lateral movement outside the lab.
- Password spraying against real accounts.

## Assessment Goals
The goal is to demonstrate a complete, auditable security assessment rather than simply run security tools.
